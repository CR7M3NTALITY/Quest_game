# Подземелье Забытых Багов 2D

Текстовый RPG-квест для практической работы по тестированию.

## Установка
1. Установите Python 3.8+
2. Откройте терминал в папке с проектом
3. Выполните: `pip install pygame`

## Запуск
`python game.py`

## Управление
- Кликайте мышью по кнопкам для выбора действий
- Исследуйте локации, сражайтесь с монстрами, покупайте предметы

## Требования к системе
- ОС: Windows/macOS/Linux
- Разрешение экрана: 1200x800 и выше

**Полное техническое задание см. в файле `TECHNICAL_SPECIFICATION.md`**
