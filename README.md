# 🏰 Подземелье Забытых Багов 2D

Текстовый RPG-квест с графическим интерфейсом, разработанный в учебных целях для отработки навыков тестирования программного обеспечения методом «чёрного ящика».

---

## 📁 Структура проекта

```text
quest_2d_game/
├── game.py                          # Основной исполняемый файл игры
├── README.md                        # Данный файл с инструкцией
├── TECHNICAL_SPECIFICATION.md       # Полное техническое задание (ТЗ)
└── assets/                          # Папка с графическими ресурсами
    ├── bg_cave.png                  # Фон: вход в пещеру
    ├── bg_fork.png                  # Фон: развилка
    ├── bg_skeleton.png              # Фон: комната скелета
    ├── bg_merchant.png              # Фон: лавка торговца
    ├── bg_boss_lair.png             # Фон: логово дракона (до победы)
    ├── bg_treasure.png              # Фон: зал с сокровищами (после победы)
    ├── char_skeleton.png            # Спрайт: скелет-воин
    └── char_merchant.png            # Спрайт: торговец
```

## 🎮 Описание игры

Игрок берет на себя роль искателя приключений, который входит в темное подземелье. Цель игры — исследовать локации, сразиться с монстрами, собрать золото, приобрести экипировку у торговца и одолеть финального босса (Дракона).
Проект специально содержит ряд преднамеренных ошибок различной природы (логические, интерфейсные, функциональные) для проведения учебного тестирования.

## 🚀 Установка и запуск

## Системные требования

ОС: Windows, macOS или Linux
Python: версии 3.8 или выше
Разрешение экрана: 1200x800 пикселей и выше
Свободное место: ~15 МБ

## Пошаговая инструкция

```text
Убедитесь, что у вас установлен Python. Проверить можно командой:
   python --version

Откройте терминал (командную строку) и перейдите в папку с проектом:
   cd путь/к/папке/quest_game

Установите необходимую библиотеку для работы с графикой:
   pip install pygame

Запустите игру:
   python game.py
```

### ⚠️ Важно: Для корректной работы игры папка assets/ со всеми изображениями должна находиться в той же директории, что и файл game.py.
